# Dokumentace Glitche

Kanonická dokumentace projektu — **zdroj pravdy je tady na GitHubu**. Dřív žila v Google Docs; teď se v Docs nechávají jen odkazy sem.

## Návrh a fungování

- [`popis-fungovani-glitche.md`](./popis-fungovani-glitche.md) — kanonický popis toho, jak Glitch funguje (obsahový model, feed, boardy, fork, Tinybot, doporučovací systém, kurátorství, wellbeing a bezpečí, vztah k p-book).
- [`vymezeni-zakaz-socialnich-siti.md`](./vymezeni-zakaz-socialnich-siti.md) — proč zakazovat sociální sítě nefunguje a jak Glitch stavíme jinak.
- [`modely-fungovani-socialnich-siti.md`](./modely-fungovani-socialnich-siti.md) — rešerše modelů fungování sociálních sítí (podklad pro návrh).

## Obsah a karty

- [`typy-obsahu.md`](./typy-obsahu.md) — přehled 7 typů obsahu (Basic Glitch, Rychlá výzva, Wellbeing, Fun fact, Najdi chybu, Historická osobnost, Argumentuj), stavy důvěry, relace, source of truth.
- [`karta-basic-glitch.md`](./karta-basic-glitch.md) — obecná šablona sekcí Glitche (kontrakt / podání / úrovně / kontext pro bota / bezpečnost) na příkladu „Hra života".
- [`napady-argumentuj.md`](./napady-argumentuj.md) — zásobník tvrzení pro typ Argumentuj.

## Archiv

- [`archiv/`](./archiv/) — starší, nahrazené verze dokumentů. Ponecháno pro historii, není to zdroj pravdy.
