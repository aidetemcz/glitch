# Informatika → Umělá inteligence

Glitche o umělé inteligenci — jak funguje, doporučovací systémy, bias a férovost,
soukromí, autorství a etika. Napojení na koncepty `umela-inteligence-*` a
`digitalni-obcanstvi-*` z [mapy konceptů](../../../knowledge-map/).

Zatím převážně typ **Argumentuj** (názorová tvrzení k promýšlení). Přibývat budou
Basic Glitche, Najdi chybu a další.
