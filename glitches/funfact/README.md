# Fun fact

Rozklikávací Glitch pro zpestření feedu. Po rozkliku vysvětlení konceptu + možnost si o tom popovídat s chatbotem.

## Tok interakce

1. **Karta ve feedu** — jádro faktu (tučný titulek) + ilustrace, krátké rozvedení.
2. **Rozklik → vysvětlení konceptu** — hlubší kontext.
3. **Chat** — možnost popovídat si o tom s chatbotem.

## Navrhovaná struktura souboru *(k doladění)*

- **0 Identifikace** — id, název, verze, jazyk, stav důvěry.
- **1 Karta ve feedu** — štítek „Fun fact", ilustrace (na kontrastní dlaždici), jádro faktu (titulek), krátké rozvedení.
- **2 Vysvětlení konceptu** — co za faktem stojí, souvislosti.
- **4 Kontext pro chatbota** — fakta, hranice tématu, co bot nesmí.
- **6 Bezpečnost.**

Soubory: `{tema}-{nazev}.md`, např. `bug-mura-harvard-mark-ii.md`.
